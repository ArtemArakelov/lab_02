# streamstats

Потоковый анализатор файлов с событиями (CSV и JSONL). Читает файлы построчно, не загружая их целиком в память, считает статистику и записывает JSON-отчёт.

## Установка

```bash
pip install -e ".[dev]"
```

## Использование

```bash
python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json
python -m streamstats analyze INPUT --format jsonl --skip-invalid
```

- `--format` — формат входных файлов (обязателен).
- `--output` — файл для отчёта; без него отчёт печатается на экран.
- `--skip-invalid` — пропускать повреждённые строки (по умолчанию обработка останавливается).

## Формат событий

Обязательные поля:

- `timestamp` — дата и время в формате ISO 8601;
- `level` — DEBUG, INFO, WARNING, ERROR или CRITICAL;
- `source` — непустая строка;
- `message` — строка.

CSV: первая строка содержит заголовок с этими четырьмя столбцами. JSONL: по одному JSON-объекту в строке.

## Что считает отчёт

- общее число событий;
- число событий каждого уровня;
- число событий каждого источника;
- топ-5 источников с ошибками уровней ERROR и CRITICAL;
- первая и последняя временные метки;
- число пропущенных строк.

Статистика нескольких файлов объединяется в один отчёт.

## Повреждённые строки

- По умолчанию обработка останавливается, в сообщении указываются файл и номер строки, код выхода `2`.
- С флагом `--skip-invalid` строка пропускается, в лог пишется WARNING, а число пропущенных строк попадает в отчёт.

## Коды выхода

- `0` — успех;
- `2` — ошибка данных или конфигурации;
- `1` — ошибка доступа к файлу.

## Структура проекта

- `models.py` — событие и его проверка;
- `parsers.py` — парсеры CSV и JSONL (генераторы);
- `analysis.py` — подсчёт статистики;
- `report.py` — формирование JSON-отчёта;
- `errors.py` — исключения;
- `__main__.py` — командная строка.
